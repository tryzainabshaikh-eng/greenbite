# 🌱 GreenBite - Professional Plant Care Website

A complete, professional website for plant identification and care guidance. Built with modern web standards and a beautiful, editorial design aesthetic.

## 🎨 Website Structure

### **Home Page** (Landing Page)
The main landing page with multiple sections:

1. **Navigation Header**
   - Fixed top navigation with logo
   - Smooth scroll links to sections
   - "Get Started" CTA button
   - Responsive mobile menu

2. **Hero Section**
   - Large, impactful headline: "Your plants deserve better care"
   - Beautiful garden image (AI-generated)
   - Call-to-action buttons
   - Social proof with star ratings
   - Floating stat card showing "8 Plants Ready to identify"

3. **Features Section**
   - Three-column grid layout
   - Instant Identification
   - Detailed Care Guides
   - Growth Tracking
   - Each feature in a card with hover effects

4. **How It Works Section**
   - Split layout with image and steps
   - Numbered steps (01-04)
   - Beautiful seedling image
   - Clear, actionable instructions

5. **Plants Section**
   - Grid of 8 supported plants
   - Each plant in a card with emoji
   - Hover effects for interactivity
   - Clean, organized layout

6. **CTA Section**
   - Large gradient banner
   - Compelling headline
   - Strong call-to-action button
   - Dark green gradient background

7. **Footer**
   - Four-column layout
   - Product links
   - Company information
   - Legal links
   - Copyright notice

### **Identify Page**
- Clean, focused interface
- Two large action buttons (Demo Mode, Upload Photo)
- Grid of supported plants
- Back navigation to home

### **Result Page**
- Large plant display with emoji
- Confidence percentage badge
- Detailed care guide with icons
- Two action buttons (Log Growth, Identify Another)
- Beautiful gradient header

### **Journal Page**
- Clean empty state
- Call-to-action to start identifying
- Minimal, focused design

## 🎯 Design Philosophy

### **Color Palette**
- **Cream Base**: `#faf8f3` - Warm, paper-like background
- **Forest Green**: `#2d4a2d` - Deep, natural primary color
- **Sage Green**: `#4a6b4a` - Soft, organic accent
- **Light Sage**: `#f5f0e6` - Subtle section backgrounds
- **Ink Brown**: `#1a1612` - High contrast text
- **Ember Orange**: `#b86b42` - Warm accent for ratings

### **Typography**
- **Fraunces Serif**: Editorial, elegant headings
- **Inter Sans**: Clean, readable body text
- **Font Weights**: 300 (light), 400 (regular), 500 (medium), 600 (semibold), 700 (bold)
- **Hierarchy**: Clear visual hierarchy with size and weight

### **Layout Principles**
- **Max-width containers**: 6xl (1152px) for content
- **Generous spacing**: py-20 for sections, gap-8 for grids
- **Responsive design**: Mobile-first, works on all screen sizes
- **Visual balance**: Asymmetric layouts where appropriate
